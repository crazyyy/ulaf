== Installation ==

Install using the WordPress built-in Plugin installer, or extract the zip file and drop the contents in the wp-content/plugins/ directory.

Activate the plugin through the 'Plugins' menu.

Go to UltimaKit in the admin sidebar.

Enable only the modules you need to keep your site lightweight.

== Frequently Asked Questions ==

= Why should I use UltimaKit instead of installing separate plugins? =
Every plugin you install adds database overhead and potential security risks. UltimaKit allows you to replace 20+ single-purpose plugins (like Duplicate Post, SVG Support, Disable Gutenberg) with one clean, optimized codebase.

= Does enabling many modules slow down my site? =
No. UltimaKit uses a modular architecture. If you do not enable a module, its code does not run. It is significantly faster than running 20 separate plugins.

= Can I use this for client sites? =
Yes! The "White Label" and "Clean Admin" features make it perfect for agencies who want to hand over a clean, professional dashboard to clients.

= Is it compatible with WooCommerce? =
Yes. We have dedicated WooCommerce optimization modules (Free & Pro) to speed up your store, such as disabling cart fragments and hiding out-of-stock products.
