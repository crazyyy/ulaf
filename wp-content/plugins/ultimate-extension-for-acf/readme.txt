== Description ==

Ultimate Extension for ACF enhances your Advanced Custom Fields (ACF) Flexible Content editing experience with powerful image preview functionality and performance optimizations.

= Key Features =

* **Image Previews**: Add preview images to ACF flexible content layouts for better visual management
* **Multisite Support**: Automatic fallback to main site images in multisite setups
* **Performance Optimised**: Caching and optimised database queries for faster loading
* **ACF Compatibility**: Works with both legacy (v5.6-v6.4.x) and current (v6.5+) ACF versions
* **Admin Interface**: Easy-to-use settings page for managing preview images
* **Accordion Behaviour**: Only one layout open at a time for better UX
* **Translation Ready**: Full internationalisation support with .pot file included

= How It Works =

1. Install and activate the plugin
2. Go to ACF Field Groups → Image Preview Settings
3. Upload preview images for your flexible content layouts
4. Enjoy enhanced visual management of your ACF flexible content

= Multisite Support =

The plugin automatically handles multisite setups:
- Uses site-specific preview images when available
- Falls back to main site images when subsite doesn't have specific previews
- Correctly generates image URLs across different sites
- Properly handles file paths in multisite environments

= Security =

This plugin follows WordPress security best practices and implements industry-standard security measures to protect your installation.

= Requirements =

* WordPress 5.0 or higher
* PHP 7.4 or higher
* Advanced Custom Fields (ACF) v5.6+ or v6.5+

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/ultimate-extension-for-acf/`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Ensure Advanced Custom Fields (ACF) is installed and active
4. Go to ACF Field Groups → Image Preview Settings to configure

== Frequently Asked Questions ==

= Does this plugin work with ACF Pro? =

Yes, this plugin is designed to work with both ACF Free and ACF Pro versions 5.6+ and 6.5+.

= Is it compatible with multisite? =

Yes, the plugin includes full multisite support with automatic fallback to main site images.

= Does it affect performance? =

No, the plugin is optimised for performance with caching and efficient database queries.

= Can I translate the plugin? =

Yes, the plugin is fully translation-ready and includes a .pot file for translators.
