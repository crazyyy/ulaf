Displays a default alt text for images on your site when none is set — simple, fast, and great for SEO.

== Description ==

**Default Alt Text** is a lightweight **SEO Plugin** that helps improve your site’s SEO and accessibility by ensuring every image always has an alt attribute. If an image in the Media Library doesn’t have an alt text set, this plugin will automatically use the image’s title instead, on the front-end only,so your database remains untouched.

This is especially useful for sites with lots of images uploaded without alt text, helping you maintain better SEO and a more accessible site without editing each image manually.

= Features =

- Displays default alt text if none is set
- Uses the image title as fallback alt text
- Does not modify Media Library data
- Improves SEO and accessibility
- Lightweight and simple,no settings needed

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. That’s it! No configuration needed.

== Frequently Asked Questions ==

= Does this plugin save the alt text in the database? =
No. It only displays a default alt text on the front-end when the image’s alt is empty. Your Media Library data stays unchanged.

= What does the default alt text use? =
It uses the image’s title if no alt text is found.

= Will this help with SEO? =
Yes! Search engines prefer images with descriptive alt text. This very helpful SEO plugin covers missing alt tags automatically.
